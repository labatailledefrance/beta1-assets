# beta1-assets

Assets tiers de la beta 1 de **La Bataille de France** : modèles 3D, textures, sons, polices.

**Ce dépôt ne contient aucun asset.** Il contiendra un **manifeste** (URL, hash, licence SPDX, auteur, modifications) et les scripts qui téléchargent, vérifient et convertissent chaque asset. Le projet ne redistribue donc rien dans git ; le jeu déployé, lui, sert les assets aux joueurs, d'où la liste fermée de licences.

**En construction** : manifeste et scripts portés des prototypes P-24 et P-25.

## Règles

- Licences acceptées : **CC0-1.0, CC-BY-4.0, OFL-1.1**, vérifiées par la CI. Les auteurs CC-BY sont cités dans l'écran de crédits, généré depuis le manifeste.
- **Pas de modèles 3D générés par IA.**
- Direction artistique low-poly, textures peu détaillées : la passe pixel art du client unifie le reste.
- Certaines sources demandent un compte (Sketchfab : jeton personnel `SKETCHFAB_TOKEN`) ; les autres se téléchargent sans compte.

Contribution : [CONTRIBUTING.md](https://github.com/labatailledefrance/.github/blob/main/CONTRIBUTING.md). Licence des scripts : AGPL-3.0-or-later ; chaque asset garde la sienne.
